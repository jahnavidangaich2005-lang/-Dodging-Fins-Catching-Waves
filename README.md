# -Dodging-Fins-Catching-Waves
Shark–human interactions pose safety risks for surfers and coastal tourists in regions like Australia and USA. Using geospatial analytics, this study maps shark incident hotspots and seasonal trends, showing encounters are linked to human coastal activity and environmental conditions, supporting informed risk management.
